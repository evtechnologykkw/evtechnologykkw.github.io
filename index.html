LEARNING ROADMAP

จากพื้นฐานระบบสมองกลฝังตัว สู่เทคโนโลยียานยนต์ไฟฟ้า

การเรียนรู้เทคโนโลยียานยนต์ไฟฟ้า ควรเริ่มจากองค์ความรู้พื้นฐาน แล้วค่อยพัฒนาความสามารถด้าน Hardware, Software และ Control จนสามารถบูรณาการเป็นระบบขับเคลื่อน และระบบยานยนต์ไฟฟ้าได้จริง

01

Microcontroller

เรียนรู้โครงสร้างไมโครคอนโทรลเลอร์ Digital I/O, Timer, Interrupt, ADC และ PWM

02

Embedded Programming

พัฒนาโปรแกรมระบบสมองกลฝังตัว เพื่ออ่าน Sensor ประมวลผล และควบคุมอุปกรณ์แบบ Real-Time

03

Sensors & Signal Processing

เรียนรู้การวัดแรงดัน กระแส ตำแหน่ง ความเร็ว อุณหภูมิ และการปรับสภาพสัญญาณ

04

PCB Design

จาก Schematic สู่ PCB จริง โดยคำนึงถึง Grounding, Isolation, EMI/EMC และความปลอดภัย

05

Power Electronics

เรียนรู้ Semiconductor, Converter และการควบคุม การแปลงพลังงานไฟฟ้า

06

Gate Driver

เชื่อมระบบควบคุมกับ MOSFET, IGBT หรือ SiC พร้อม Isolation และ Protection

07

3-Phase Inverter

สร้างและควบคุม Inverter สำหรับแปลง DC เป็นไฟฟ้า AC สามเฟส

08

Motor Control

ควบคุมแรงบิด ความเร็ว กระแส และแรงดัน ด้วย Control Algorithm

09

PMSM / IPMSM Drive

บูรณาการ Motor, Inverter, Sensor และ Field-Oriented Control เป็นระบบขับเคลื่อนจริง

10

EV Technology

รวม Battery, Power Electronics, Embedded Systems, Motor, Control และ Communication เป็นระบบยานยนต์ไฟฟ้า

แนวคิดสำคัญ: เริ่มจากพื้นฐาน → เข้าใจระบบย่อย → สร้าง Hardware และ Software → ทดสอบ → บูรณาการ → EV Technology

REAL EV LEARNING ENVIRONMENT

EV Technology Laboratory

พื้นที่เรียนรู้และปฏิบัติการ สำหรับยานยนต์ไฟฟ้า ระบบแบตเตอรี่แรงดันสูง การชาร์จ การตรวจวัด การบำรุงรักษา และการวิเคราะห์ระบบจริง

01 — EV VEHICLE

Electric Vehicle

ศึกษาโครงสร้าง ระบบไฟฟ้าแรงดันสูง ระบบขับเคลื่อน การตรวจสอบ และการบำรุงรักษา ยานยนต์ไฟฟ้าจริง

02 — HV BATTERY

High Voltage Battery & BMS

เรียนรู้โครงสร้าง Battery Module, Battery Pack, High-Voltage Connection, BMS และความปลอดภัย ในระบบแบตเตอรี่

03 — HANDS-ON

EV Hands-on Training

ฝึกการถอดประกอบ ตรวจวัด ทดลอง เชื่อมต่ออุปกรณ์ วิเคราะห์ข้อมูล และแก้ปัญหาระบบ EV

04 — EV CHARGING

Charging & Energy

ศึกษาระบบชาร์จ อุปกรณ์ EVSE การส่งผ่านพลังงาน การตรวจวัด และการจัดการพลังงาน สำหรับยานยนต์ไฟฟ้า

05 — EV MOTORCYCLE

Electric Motorcycle

เรียนรู้ระบบขับเคลื่อน Motor Controller, Battery, Wiring และการประยุกต์ เทคโนโลยี EV กับรถจักรยานยนต์

06 — TRAINING LAB

EV Training Systems

ชุดทดลองสำหรับ การเรียนรู้ Sensor, Motor, Battery, Controller, Measurement และระบบย่อยของ EV

Hands-on Learning: ทฤษฎี → ลงมือปฏิบัติ → ตรวจวัด → วิเคราะห์ → แก้ปัญหา → ทดสอบ → System Integration

EV Motorcycle Conversion

Battery BMS Motor Controller
02 — PCB & EMBEDDED

PCB & Embedded Systems

พัฒนา Schematic, PCB, Sensor Interface และ Embedded Controller สำหรับงานควบคุม และระบบยานยนต์ไฟฟ้า

PMSM / IPMSM Motor Control

PMSM FOC DSP Inverter
04 — BATTERY

Battery & BMS

ศึกษาและพัฒนาระบบ Battery Pack, Cell Monitoring, Temperature, Protection และ Battery Management System

Battery BMS Safety Monitoring
05 — POWER ELECTRONICS

Power Electronics & Inverter

ออกแบบและทดลอง Gate Driver, Power Semiconductor, DC-Link และ 3-Phase Inverter สำหรับระบบขับเคลื่อนไฟฟ้า

MOSFET IGBT SiC Inverter
06 — SYSTEM INTEGRATION

EV System Integration

บูรณาการ Battery, Power Electronics, Embedded System, Motor, Control และ Communication ให้ทำงานร่วมกันเป็นระบบ EV

Hardware Software Control EV System
