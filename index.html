LEARNING ROADMAP

จากพื้นฐานระบบสมองกลฝังตัว สู่เทคโนโลยียานยนต์ไฟฟ้า

การเรียนรู้เทคโนโลยียานยนต์ไฟฟ้า ควรเริ่มจากองค์ความรู้พื้นฐาน แล้วค่อยพัฒนาความสามารถด้าน Hardware, Software และ Control จนสามารถบูรณาการเป็นระบบขับเคลื่อน และระบบยานยนต์ไฟฟ้าได้จริง

01

Microcontroller

เรียนรู้โครงสร้างไมโครคอนโทรลเลอร์ Digital I/O, Timer, Interrupt, ADC และ PWM

02

Embedded Programming

พัฒนาโปรแกรมระบบสมองกลฝังตัว เพื่ออ่าน Sensor ประมวลผล และควบคุมอุปกรณ์แบบ Real-Time

03

Sensors & Signal Processing

เรียนรู้การวัดแรงดัน กระแส ตำแหน่ง ความเร็ว อุณหภูมิ และการปรับสภาพสัญญาณ

04

PCB Design

จาก Schematic สู่ PCB จริง โดยคำนึงถึง Grounding, Isolation, EMI/EMC และความปลอดภัย

05

Power Electronics

เรียนรู้ Semiconductor, Converter และการควบคุม การแปลงพลังงานไฟฟ้า

06

Gate Driver

เชื่อมระบบควบคุมกับ MOSFET, IGBT หรือ SiC พร้อม Isolation และ Protection

07

3-Phase Inverter

สร้างและควบคุม Inverter สำหรับแปลง DC เป็นไฟฟ้า AC สามเฟส

08

Motor Control

ควบคุมแรงบิด ความเร็ว กระแส และแรงดัน ด้วย Control Algorithm

09

PMSM / IPMSM Drive

บูรณาการ Motor, Inverter, Sensor และ Field-Oriented Control เป็นระบบขับเคลื่อนจริง

10

EV Technology

รวม Battery, Power Electronics, Embedded Systems, Motor, Control และ Communication เป็นระบบยานยนต์ไฟฟ้า

แนวคิดสำคัญ: เริ่มจากพื้นฐาน → เข้าใจระบบย่อย → สร้าง Hardware และ Software → ทดสอบ → บูรณาการ → EV Technology
