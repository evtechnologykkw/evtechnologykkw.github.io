ONE-DAY TRAINING

ตารางอบรมหลัก 6 ชั่วโมง

09:00–09:30
C2000 & Control Architecture ภาพรวม Embedded Control และเส้นทางจาก Software สู่ Hardware
09:30–10:30
Hardware Interface & Protection Shield, Buffer, Ground, Signal Level, Connector และ Protection
10:30–11:30
Hardware Bring-Up ต่อชุดทดลอง, ตรวจ Power, Signal และ Test Point
11:30–12:00
First Simulink Model Model → Build → Download → Hardware
13:00–14:00
PWM Fundamentals Frequency, Duty Cycle, Counter และ Compare
14:00–15:00
PWM with MATLAB / Simulink สร้าง PWM และปรับ Duty Cycle บน Hardware จริง
15:00–16:00
Measurement, Debug & Final PWM Challenge วัด Waveform ด้วย Oscilloscope, วิเคราะห์ปัญหา, ปรับ Frequency และ Duty Cycle และทำ PWM Commissioning Challenge เพื่อยืนยันว่าผู้เข้าอบรมสามารถ สร้างและตรวจสอบสัญญาณได้จริง
OPTIONAL
16:00–17:00
Advanced Demonstration — dSPACE / Inverter กิจกรรมเสริมหลังจบหลักสูตรหลัก สำหรับผู้ที่สนใจเส้นทางการพัฒนาต่อ ไปยัง Rapid Control Prototyping, dSPACE MicroLabBox, Gate Driver, Inverter และ Advanced Motor Control

FINAL PWM CHALLENGE

Certificate ต้องมาจาก “ทำได้จริง”

ก่อนจบหลักสูตร ผู้เข้าอบรมจะได้รับโจทย์ ให้สร้าง PWM ตาม Specification และพิสูจน์ผลด้วย Oscilloscope

PWM Commissioning Challenge

Target Frequency = 10 kHz
Duty Cycle = 60 %
Output = C2000 PWM Channel
Verification = Oscilloscope
